# 飞书手机快速打卡

## 推荐入口：表单视图

选择 `04_打卡记录` 的多维表格表单视图。表单视图会把提交结果直接写入同一数据表，适合生成固定链接或二维码，并且移动端只负责填写和提交，路径最稳定。[飞书官方说明](https://www.feishu.cn/content/article/7581406132237782223)

不推荐按钮字段：它会增加一次点击和额外自动化配置；也不推荐直接编辑移动端表格，因为系统字段太多，容易误填。

## 一次性配置

1. 在桌面端打开 `04_打卡记录`，新建“表单视图”，命名为“快速打卡”。
2. 表单只保留以下字段，并按顺序排列：
   - `类别`：必填，单选。
   - `投入分钟`：TIME 类别的必填数值。
   - `数量`：LeetCode 的必填题数。
   - `内容`：可选。
3. 配置条件显示：
   - 类别为 LeetCode 时，只显示 `数量`，题目标题改为“题数”。
   - 类别为科研、课程、英语或 408 时，只显示 `投入分钟`，题目标题改为“分钟”。
4. 不把这些系统字段放进表单：`打卡时间`、`创建时间`、`日期`、`单位`、`所属目标`、`所属任务`、`备注`。
5. 发布表单，仅允许自己填写。将链接发送给自己的飞书“收藏”或添加到手机桌面快捷入口。

飞书表单支持字段条件控制、链接和二维码分发；提交后数据直接进入原表，无需二次搬运。[飞书表单功能说明](https://www.feishu.cn/content/article/7581406132237782223)

## 每次打卡

通常只做三次点击：选择类别、输入一个数值、提交。`内容` 只有在想留下说明，或同一天同类别存在多个任务时才填写；若需要精确匹配任务，内容填写任务名称。

映射规则：

| 类别 | 用户填写 | 内部单位 |
|---|---:|---|
| 英语 | 投入分钟 | minute |
| 408 | 投入分钟 | minute |
| 科研 | 投入分钟 | minute |
| 课程 | 投入分钟 | minute |
| LeetCode | 数量 | problem |

创建时间由飞书自动生成。Hourly Daily Job 会回填业务日期、打卡时间、单位、所属目标和可推断的所属任务，并重算全部统计。正常打卡无需填写任何 ID，也不要修改长期目标当前值。
