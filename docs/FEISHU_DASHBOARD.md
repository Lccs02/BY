# 飞书仪表盘设计

## 支持边界

仪表盘及组件布局需要在飞书多维表格界面创建；本项目未发现可可靠创建并完整配置仪表盘组件的公开服务端 API，因此没有声明“已通过 API 创建”。官方产品将仪表盘列为多维表格的零代码界面能力，可参考[飞书开放平台](https://open.feishu.cn/?lang=zh-CN)。

在左侧 **新建 → 仪表盘**，命名为“保研总览”。

## 第一屏

第一行放三个倒计时指标卡，数据来自 `02_阶段里程碑`：

- 距离 2027-02-01 套磁剩余天数；
- 距离 2027-05-31 夏令营准备完成剩余天数；
- 距离 2027-07-01 夏令营阶段剩余天数。

第二行放今日完成率、本周完成率、本周计划时间、本周实际时间。任务完成率分母排除“跳过”。

第三行放科研投入、课程投入、英语投入、LeetCode 进度、408 进度。时间统一显示小时但底层继续存分钟；LeetCode 显示 `当前值 / 220`。

第四行放风险目标数、连续活跃天数。风险数仅统计 AT_RISK 与 CRITICAL；连续活跃天数按 `04_打卡记录.日期` 去重后计算。

## 显示规范

- 风险颜色：ON_TRACK 绿色、SLIGHTLY_BEHIND 黄色、AT_RISK 橙色、CRITICAL 红色、COMPLETED 灰蓝色。
- 百分比字段底层为 0–100，组件不要再次乘以 100。
- 第一屏优先保证手机端两列布局；趋势图放在指标卡下方，避免首屏横向滚动。
